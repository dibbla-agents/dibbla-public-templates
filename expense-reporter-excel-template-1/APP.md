# Expense Reporter (Excel)

Upload PDF receipts, and an AI agent will read each one, extract expense details (vendor, amount, currency, date, category, VAT, receipt reference), and generate a formatted Microsoft Excel workbook in your OneDrive.

## Features

- Drag-and-drop or browse to upload PDF receipts (up to 20 per session)
- AI-powered expense extraction via the Dibbla AI Gateway (Claude)
- Automatic Excel workbook creation in OneDrive with formatted headers, totals row, and frozen header
- Supports multiple currencies and VAT tracking
- Preview extracted expenses before opening the workbook
